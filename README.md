# Digital Horror

Digital Horror は、Paper サーバーにデジタルホラー風の違和感やイースターエッグを加える Minecraft プラグインです。プレイヤーの視界外やサウンド、Tab リスト、表示上のブロック、アイテム名を使い、ゲーム進行を大きく妨げずに一時的な恐怖を演出します。

## 主な機能

- プレイヤー本人が送信したように見える偽チャット、就寝警告、文字化けアクションバーを表示します。
- ProtocolLib を使用し、Tab リストに短時間だけ存在する偽プレイヤーを表示します。
- プレイヤーの背後に監視者を出現させ、視界に入った瞬間に消します。
- プレイヤーが移動を止めた後の足音、遠方の環境音、突発的な無音、低いガラス破壊音を再生します。
- 壁の中から幻影の採掘音を鳴らし、プレイヤーが音源へ近づくと即座に停止します。
- ドアが開いたように見せたり、手持ちアイテムの名前を一時的に変えたり、水中で突然暗闇にしたりします。
- すべての演出は `config.yml` で個別に有効化でき、確率や間隔、メッセージも調整できます。

## 動作要件

- Paper 1.21.4 系
- Java 21
- ProtocolLib 5.3.0

`paper-plugin.yml` で ProtocolLib を依存関係に指定しています。ProtocolLib がない場合、本プラグインは読み込まれません。

## ビルド

Windows では次のコマンドを実行します。

```powershell
.\gradlew.bat clean build
```

ビルド後の JAR ファイルは `build/libs/digital-horror-1.0.0.jar` です。Gradle Wrapper を利用できない場合は、Java 21 と Gradle 9.6 以降を用意して `gradle clean build` を実行してください。

## 導入

1. Paper サーバーを停止します。
2. ProtocolLib 5.3.0 と生成した JAR ファイルをサーバーの `plugins` ディレクトリへ配置します。
3. サーバーを起動し、生成された `plugins/DigitalHorror/config.yml` を編集します。
4. 設定変更後はサーバーを再起動します。

## 設定

`config.yml` には、各設定の用途と推奨範囲を日本語コメントで記載しています。確率は `0.0` から `1.0`、時間は特記がない限り tick 単位で指定します。20 tick は約 1 秒です。

メッセージ内の `%player%` は対象プレイヤー名に置き換えられます。色コードには `&` を使用できます。たとえば `&7%player%` は、プレイヤー名を灰色で表示します。

## 注意事項

- 一部の演出では、クライアント側の表示変更や短時間のブロック変更を利用します。演出の終了時には、可能な限り元の状態へ戻します。
- 驚かせる表現を含むため、参加者の同意とサーバールールを確認して使用してください。
- 演出確率を高くしすぎると没入感やサーバー負荷に影響するため、初期値から少しずつ調整してください。
