# Digital Horror

Digital Horror は、Paper サーバーにデジタルホラー風の違和感やイースターエッグ演出を追加する Minecraft プラグインです。プレイヤーの視界外、サウンド、Tab リスト、表示上のブロックやアイテム名などを利用し、ゲーム進行を大きく妨げない一時的な恐怖演出を提供します。

## 主な機能

- プレイヤー本人が送信したように見える偽チャット、就寝警告、文字化けアクションバーを表示します。
- ProtocolLib を使用し、Tab リストに短時間だけ存在する偽プレイヤーを表示します。
- プレイヤーの背後に監視者を生成し、視界に入った瞬間に消去します。
- 移動停止後の足音、遠方の環境音、突発的な無音化を再生します。
- ドアが開いたように見える表示や、手持ちアイテム名の一時的な改変を行います。
- すべての演出は `config.yml` から個別に有効化し、確率や間隔、メッセージを調整できます。

## 動作要件

- Paper 1.21.4 系
- Java 21
- ProtocolLib 5.3.0

`paper-plugin.yml` の依存関係により、ProtocolLib が存在しない場合は本プラグインを読み込みません。

## ビルド

Windows では次のコマンドを実行します。

```powershell
.\gradlew.bat clean build
```

生成物は `build/libs/digital-horror-1.0.0.jar` です。Gradle Wrapper を利用できない場合は、Java 21 と Gradle 9.6 以降を用意し、`gradle clean build` を実行してください。

## 導入

1. Paper サーバーを停止します。
2. ProtocolLib 5.3.0 と生成した JAR ファイルをサーバーの `plugins` ディレクトリへ配置します。
3. サーバーを起動し、生成された `plugins/DigitalHorror/config.yml` を編集します。
4. 設定変更後はサーバーを再起動します。

## 設定

`config.yml` には各項目の用途と推奨範囲を日本語コメントで記載しています。確率は `0.0` から `1.0`、時間は特記がない限り tick 単位で指定します。20 tick は約 1 秒です。

メッセージ内では `%player%` を対象プレイヤー名に置き換えます。色コードには `&` を使用できます。たとえば `&7%player%` は灰色のプレイヤー名として表示されます。

## 注意事項

- 一部の演出はクライアント表示または短時間のブロック変更を利用します。終了時には可能な限り元の状態へ復元します。
- 驚かせる表現を含むため、参加者の同意とサーバールールを確認して使用してください。
- 演出確率を高くしすぎると没入感やサーバー負荷に影響するため、初期値から少しずつ調整してください。
